# A page nobody wrote

Somebody did, in the end.

The themes page links here to demonstrate what happens to a wiki link whose
page is missing. In a SharePoint document library the folder is listed once and
every link into it answered from that listing, so a link to a page that is not
there is marked before a reader clicks it.

A published website has no library to ask, so nothing can be marked and the
link is drawn like any other. This document is here so that clicking it lands
somewhere that explains itself rather than on a 404.
