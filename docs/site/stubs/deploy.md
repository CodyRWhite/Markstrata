# Deploying

This document exists so that the wiki links on the themes page point at
something. The page beside it renders the sample document that exercises every
feature at once, and part of what it demonstrates is `[[deploy]]`: a link
written as a page name rather than as a path.

In a SharePoint document library, following that link opens this document
inside the web part, with a trail above it back to where you came from. On a
published website there is no web part and no library, so a click hands you the
markdown file itself, which is what you are reading.

## Rollback

`[[deploy#Rollback]]` on the themes page points here, at a heading rather than
at the top of a document. Heading links work the same way: the name is turned
into the id the heading was given, and the reader lands on it.
