Release notes, build 118

Three fixes and one new setting. Nothing in this build changes how a document is stored, so there is nothing to migrate and nothing to undo.

What changed

AreaChangeIssue

Upgrading

Nothing to do. Pages keep the settings they had, and a setting that did not exist before takes the value it would have had all along.

If you pinned the old build

Unpin it first, or the new package will install beside the old one and a page will draw whichever it finds. The steps are in rolling back a build, which is the same procedure read backwards.

Still open

  • A long table in a narrow column scrolls the whole document sideways.
  • Two documents on one page each want to be the tallest thing on it.
