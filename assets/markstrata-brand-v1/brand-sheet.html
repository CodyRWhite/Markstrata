Markstrata

Markdown for SharePoint. Layers laid down in order — which is what a Markdown document is, and what a document library is.

The markTwo strata and a chevron

Two horizontal bars of decreasing width read as a heading hierarchy and as sediment layers. The wide descending chevron is the ↓ Markdown has always carried, and the direction everything in the product moves: source above, rendered page beneath. Everything is built from one unit — a 44 px bar weight with a 22 px radius on every terminal.

Drawn for each size, not scaled down

At 16 px the second stratum is removed and the remaining weights thicken. Below 32 px the gradient tile is replaced by flat teal.

LockupsFixed proportions

Wordmark cap height is 46% of the tile height, set one quarter of a tile away from it. In the tagline lockup it drops to 40%. The wordmark is outlined Selawik Bold, tracked −1.3% — metrically identical to Segoe UI, and licensed for logo use where Segoe UI is not.

Default. Site headers, docs, slides.

First contact: store listing, landing page, deck cover.

On Bedrock or Shale surfaces, and on SharePoint sections set to strong.

Narrow columns and square placements.

ColourStrata and Sediment

Strata is the brand teal, close enough to SharePoint's own teal to sit in the suite without looking borrowed. Sediment is the amber of the chevron — the one warm thing in the system, reserved for the Markdown source side of the product. One amber element per screen.

TypeSegoe UI and Cascadia Mono

SharePoint already serves Segoe UI. Loading a webfont for UI type costs a request and breaks the illusion that Markstrata is part of the page. The editor pane is the one place the product shows its own character.

UseWhat holds the mark together

Do

  • Scale the SVG; take rasters from export/.
  • Use the size-specific files rather than downscaling the master.
  • Keep the tile square with its own radius — the rounding is part of the artwork.
  • Put the mono-light glyph on photographs.
  • Read the site theme for UI chrome; keep the tile, lockup and amber ours.

Don't

  • Recolour the tile, outline it, or drop a shadow behind it.
  • Rotate, skew or flip the chevron. It points down, always.
  • Rebuild a lockup by placing the wordmark next to the tile by hand.
  • Set the wordmark as live text and call it the logo.
  • Add "for SharePoint" to the wordmark; that lives in the tagline lockup.

SPFx manifest

The base64 of the 32 px icon is in export/spfx-iconImageUrl.txt. Use officeFabricIconFontName only as a fallback — the Fluent icon font has nothing that reads as Markstrata.
